Лабораторная работа 4. Вариант 6

Инструкция запуска
Запуск в терминале:
python main.py

Инструкция запуска тестов
python -m unittest tests -v

Формулы
m_i = M · fraction_i
M — общая масса смеси, кг;
fraction_i — доля i-го компонента (от 0 до 1);
m_i — масса i-го компонента, кг.

Таблица режимов с коэффициентами
Режим	Тип смеси	Компоненты и их доли (fraction)
1	    Бетон	    цемент 0.15, песок 0.35, щебень 0.50
2	    Керамика	глина 0.60, песок 0.25, добавка 0.15
3	    Сплав	    Cu 0.70, Zn 0.25, Pb 0.05

Допустимые диапазоны
M: от 1.0 до 10000.0 (кг).

Если значение выходит за эти пределы или введено не число, программа запрашивает его повторно и пишет ошибку в журнал.

Правила классификации
Классификация массы партии выполняется через if-elif-else:

M < 100 — малая партия;

100 ≤ M ≤ 1000 — средняя партия;

M > 1000 — крупная партия.

Краткая таблица«файл → назначение»
Файл	Назначение
main.py	Точка входа, главный цикл программы
constants.py	Константы: доли компонентов смесей, диапазоны M, пороги партий
validators.py	Валидация ввода (циклы, try/except, if-elif-else)
operations.py	Расчёты масс компонентов и классификация партии
menu.py	Вывод меню и маршрутизация через match-case
logger.py	Журнал ошибок ввода (в память и файл)
